# dy-video

专门用于解析和下载抖音（Douyin）无水印超高清/高清视频、独立音频及提取视频内台词文字的轻量级工具与 Skill。基于官方移动端 Feed 接口毫秒级直出，并在遇到特殊风控时自动通过原生无头浏览器兜底。

## 解决什么问题

直接获取或下载抖音视频与音频时通常面临以下问题：
1. **官方水印遮挡**：网页或 App 直接保存的视频带有作者 ID 与抖音水印，且分辨率通常被压缩。
2. **移动端口令与短链解析繁琐**：App 分享通常为一段夹带文字与乱码的口令短链（`v.douyin.com/...`），需跟进重定向与清洗规整。
3. **音频分离与转码门槛**：提取背景音乐或原声音频通常需要额外部署复杂的转码环境与命令行。
4. **长视频与切片风控拦截**：部分视频受风控限制无法直接通过简单爬虫下载。

`dy-video` 提供一键式免配下载与解析，支持最高 1080P 超高清音画合一视频下载、原生高品质音频导出，并支持配合 Agent 多模态视听能力实现视频台词对白转写。

## 核心机制

1. **短链清洗与 302 重定向规整**：自动从各类复杂分享口令中文本提取短链并在 HTTP 协议层规整出标准作品 `aweme_id`。
2. **官方 Feed 极速通道（首选）**：基于移动端底层 Feed 接口毫秒级提取作品元数据、各档位无水印播放流及背景音乐流，零等待、零浏览器开销。
3. **无头浏览器智能兜底（Fallback）**：遇到特殊风控或复杂切片时，自动调度本地 Chrome / Edge 渲染，配置独立临时 `user-data-dir` 避免实例死锁。
4. **官方母本调度与音轨提取**：凭母本 `video_id` 直调官方出流接口获取 1080P/720P 原始无水印 MP4；提取音频时若缺少独立原声音轨，自动调度轻量 FFmpeg 提取转码，缺少依赖时支持自动静默就绪。

## 使用方式

依赖 Python 3.8+ 标准库，无需额外安装 pip 第三方依赖。

把本 Skill 目录或上级目录作为工作路径运行脚本：

```bash
# 1. 默认下载最高画质（1080P 超高清无水印视频），默认保存在系统的 Downloads 目录
python scripts/download_douyin.py "<分享文本或链接>"

# 2. 仅下载音频（默认保存为高品质 MP3，若有原声音乐流则零转码直下）
python scripts/download_douyin.py "<分享文本或链接>" --audio

# 3. 下载原生无损音频（M4A 格式，不转码直接拷贝原音轨）
python scripts/download_douyin.py "<分享文本或链接>" --audio --audio-format m4a

# 4. 指定视频清晰度（可选：1080p / 720p / 540p）
python scripts/download_douyin.py "<分享文本或链接>" -q 720p

# 5. 指定输出保存路径（支持完整文件名或目标目录）
python scripts/download_douyin.py "<分享文本或链接>" -o "./output/my_file.mp4"

# 6. 仅获取元数据与直链（不下载实体文件）
python scripts/download_douyin.py "<分享文本或链接>" --info-only --json
```
