# flywheel

可复用的 AI 开发工作流与内容处理工具集合，面向希望把 AI 协作落到实际任务中的开发者和工具使用者。能力按独立单元与成套组件组织，可以按需要选择。

| 能力 | 解决什么问题 |
| --- | --- |
| [development](development/) | 一套完整的 AI 辅助开发方法：业务理解、技术设计、测试设计、编码实现、问题处理到需求复盘 |
| [wx-fetch](skills/wx-fetch/) | 抓取并解析微信公众号文章内容，规避防爬机制与本地代理冲突 |
| [dy-video](skills/dy-video/) | 解析和下载抖音无水印超高清音视频，并支持多模态视频台词提取 |
