# 抖音视频下载与转写 (dy-video)

用于从抖音分享文本、短链或长链中解析并下载官方原始无水印视频（1080P/720P/540P）、高品质独立音频（MP3/M4A），并支持配合多模态能力提取台词口播。

## 核心机制

采用双轨解析架构：
1. **官方 Feed 极速通道（首选）**：直连底层 Feed 接口毫秒级提取元数据、各档位无水印播放流与原声音频，无浏览器开销。
2. **无头浏览器智能兜底（Fallback）**：遇特殊风控或切片时，自动调度本地 Chrome / Edge 渲染并抓取媒体流。

提取音频时若作品无独立原声流，脚本自动调度本地或便携版 FFmpeg 无损抽取转码。

## 使用方式

以本 Skill 目录作为工作目录运行内置脚本，或直接指定脚本路径：

```bash
# 默认下载最高画质视频至系统 Downloads 目录
python scripts/download_douyin.py "<分享文本或链接>"

# 仅下载音频（MP3 格式）
python scripts/download_douyin.py "<分享文本或链接>" --audio

# 指定输出路径与清晰度
python scripts/download_douyin.py "<分享文本或链接>" -q 720p -o "./output/video.mp4"

# 仅获取元数据与直链（JSON 格式）
python scripts/download_douyin.py "<分享文本或链接>" --info-only --json
```

### 参数说明

* `<分享文本或链接>`：抖音分享口令、短链接（`v.douyin.com/...`）或长链接（必需）。
* `-q, --quality <1080p|720p|540p>`：目标清晰度（默认: `1080p`；源无 1080p 时自动匹配最高画质）。
* `-a, --audio`：仅提取并下载音频。
* `--audio-format <mp3|m4a>`：音频导出格式（默认: `mp3`，可选: `m4a` 原生音轨）。
* `-o, --output <path>`：保存的目标文件或目录路径（默认保存至系统 `Downloads/`）。
* `--info-only`：仅解析元数据与直链，不执行实体文件下载。
* `--json`：以 JSON 格式输出结果。

## 场景工作流

### 场景一：下载视频或音频

直接运行脚本执行下载。交付时汇报作品标题、作者、ID、文件大小及本地绝对路径的 Markdown 链接。遇失效或私密视频明确说明状态，不伪造直链。

### 场景二：提取视频台词与口播（语音转文字）

不依赖本地或第三方 ASR 库（如 Whisper）。利用多模态视听感知直读转写：

1. **下载临时媒体文件**：运行脚本将目标视频保存至临时路径（如系统下载目录）。
2. **多模态直读转写**：Agent 调用 `view_file` 工具读取该 `.mp4` 文件，直接提取逐句对话、口播及关键文字，按对话轮次或要点干练排版。
3. **即时清理临时文件**：完成转写后立即删除临时视频文件，保持环境整洁。
